## После регистрации callback пользователем, 1 ноября 2026

Пользователь самостоятельно добавил redirect URI в Google OAuth Platform. Агент OAuth-настройки не менял. В IAB штатная `/sign-in?redirect_url=%2Fstructures` вернула авторизованную страницу с именем аккаунта и кнопкой выхода. Тестовые JWT/cookies не подставлялись. Блокер `redirect_uri_mismatch` на preview nzkv8xbbs закрыт.

Через UI создан проект `OAuth QA 2026-11-01`: Stone Room 11×15×8, позиция -20/-4/-30, поворот 90°, дубовый пол, северный проём, остальные материалы — каменные кирпичи. Сохранение завершилось сообщением `Сохранено. Версия 1.`. После reload Google-сессия восстановилась, сцена сохранила параметры. Затем выполнены `Новый проект` → выбор проекта из облачного списка → подтверждение загрузки: параметры версии 1 восстановились с сообщением `Проект открыт.`. Высота изменена на 10 и повторно сохранена как версия 2.

Для проверки разделения серверной версии и черновика локальная высота затем изменена на 12 без сохранения. Нажата `Скачать серверную версию`: UI сообщил `Скачана сохранённая серверная версия. Локальные правки в неё не входят.`, высота 12 и dirty сохранились. Однако предварительно установленное событие download вновь завершилось таймаутом через 12000 мс; локальный файл инструменту не предоставлен. Поэтому вход/сохранение/reload/открытие/изменение/повторное сохранение подтверждены настоящей Google-сессией, UI серверного экспорта прошёл, но содержимое полученного browser-файла пока независимо не проверено.

Пользователь отдельно подтвердил, что скачивание в его браузере работает. Это свидетельство ручной доставки файла, а не свидетельство поломки сайта из-за таймаута IAB. Для завершения проверки содержимого нужен именно этот файл, предоставленный пользователем в разрешённой папке либо вложением; чтение защищённого Downloads и обход запрета не нужны.
