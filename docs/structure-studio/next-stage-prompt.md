Перед экспортом сверь официальную актуальную спецификацию Sponge Schematic и совместимость WorldEdit. Выбери и документируй Minecraft/DataVersion явно; визуальные ресурсы Java 26.1.2 сами по себе не определяют версию экспорта. Реализуй серверный адаптер .schem из сгенерированных ячеек с NBT, палитрой, индексами, реальными min/max, offset и gzip. Сохрани разницу solid/air/void: air очищает, void и разреженные пропуски не должны неожиданно очищать мир. Не экспортируй конфликтную или превышающую лимиты геометрию. Для сохранённых проектов проверяй owner через существующую Auth.js-сессию и используй общий сервис; при экспорте текущей локальной сцены явно определи сценарий и валидируй документ на сервере. Не принимай произвольный NBT или исполняемый код.

Добавь понятное скачивание из редактора, состояния загрузки/ошибки/повтора; протестируй повороты прямоугольной комнаты, отрицательные координаты, палитру, индексы, дверные проёмы, воздух и границы.
